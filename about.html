About DeKUT Smart Library Hub

A digital solution designed to increase student engagement with university library resources.

The Problem We Address

Low Library Usage

Many students depend on general web searches instead of using reliable academic library resources.

Resource Awareness

Students often do not know the books, journals and digital resources available to them.

Digital Challenges

Existing library systems can be difficult to navigate, reducing student interaction.

Our Proposed Solution

The DeKUT Smart Library Hub is a simple technology-based website that brings library resources together in one easy-to-use platform. Students can search resources, receive AI guidance, access digital materials and locate physical resources using QR codes.

Smart Search

Students quickly discover books, journals and academic materials.

AI Support

Provides instant guidance on finding and using resources.

QR Navigation

Helps students locate library sections faster.

Benefits of the Solution

Students

Improved access to quality academic materials and better research skills.

University

Better utilization of library investment and improved academic performance.

Library Staff

Easier communication with students and increased resource usage.

Project Feasibility

Technology

Can be developed using simple web technologies such as HTML, CSS and JavaScript.

Cost Effective

Requires minimal infrastructure because it is a web-based platform.

Future Growth

Can later include real databases, login systems and advanced AI features.
